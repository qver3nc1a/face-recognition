Programming language: Python

## Topic and implementation

I will implement a program that detects human faces in an image and determines their locations. I will use the Viola-Jones method to detect faces and implement the Haar Cascade algorithm based on the method. I will implement the key parts of the algorithm myself.

### Problem:
Detecting human faces in an image and determining their location.
### Core of the exercise:
Implementation of the key parts of the Haar Cascade algorithm.
### Algorithms and data structures:
I will fill in the exact algorithms and data structures after I have become more familiar with the Viola-Jones method.
### Inputs:
The program receives an image file as input, from which it searches for human faces and determines their locations.
